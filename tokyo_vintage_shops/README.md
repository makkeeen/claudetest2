## ご利用にあたっての注意

店舗の住所・営業状況・SNSアカウントは変更されることがあります。来店前やご利用前に、必ず各店舗の公式サイト・Instagramで最新情報をご確認ください。
Instagram URLは検索エンジンの検索結果リンクに実在することを確認した上で採用していますが、現在もアカウントが本人により運用されているかまでは毎回保証できません。

## 各駅ファイルの調査ルール（Routine用）

1. 既存の店舗と重複しないよう、店舗名・住所で照合してから新規追加すること
2. 閉店が確認できた店舗は「除外した店舗」セクションに理由付きで移動すること
3. Instagram URLは検索結果に実際にリンクとして出現したものだけを採用し、要約文にしか登場しないURLは採用しないこと
4. 確認できない項目は「不明」と書き、推測・捏造しないこと
5. 変更があった駅ファイルのみ更新し、ファイル末尾の「更新履歴」に日付と変更点を追記すること
